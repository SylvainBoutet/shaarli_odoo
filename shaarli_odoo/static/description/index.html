Shared Bookmarks

Save, tag and share web bookmarks inside Odoo

Shared Bookmarks lets your team save, tag and share web bookmarks in Odoo, publish the public ones on a bookmark page of your website, and archive the content of a page to read it later.

The problem it solves

Useful links end up scattered in browsers, chat messages and emails, and nobody finds them when they are needed. This module keeps them in one Odoo app, with an owner, tags, notes and a public or private status, in the spirit of the Shaarli link sharing tool.

Key features

  • Bookmarks with title, URL, description, rich text notes, color tags and an owner, in kanban, list and form views.
  • Private by default: each user sees his own bookmarks and the public ones, and only modifies his own.
  • Public bookmarks are listed on the website at /bookmarks, with tag filter, search on title and description, pagination and a detail page per bookmark.
  • Page archiving: one click stores the HTML of the bookmarked page on the record, viewable even if the site changes or disappears.
  • Click counter and last click date, with graph and pivot statistics by domain and month for bookmark managers.
  • Chatter and activities on every bookmark; search and grouping by domain, owner and date.
  • JSON-RPC route /api/bookmarks/add (logged in users) to add a bookmark with its tags from a script or a bookmarklet.
  • Two access groups: Bookmark User and Bookmark Manager.

Getting started

  1. Install the module: the Website app is installed with it.
  2. Give your users the Bookmark User or Bookmark Manager access in Settings > Users.
  3. Open the Bookmarks app, create a bookmark with its URL and tags, and tick Public to share it.
  4. Click Archive Page on a bookmark to store a copy of the page.
  5. Visit /bookmarks on your website to see the public bookmarks.

Data sent to external services

Archiving a page downloads it from its own address. At the same time, the domain of the bookmark is sent to the Google favicon service to fetch the site icon. Nothing is sent outside of Odoo as long as no page is archived.

Compatibility

  • Odoo 19.0, Community and Enterprise.
  • Dependencies: base, web, mail, website. Python libraries requests and Pillow, already required by Odoo.

FAQ

Can other users see my bookmarks?
Only the ones you mark as Public. Bookmark managers see and modify all bookmarks.

Are public bookmarks visible to website visitors?
Yes, on the /bookmarks page and its detail pages, without login.

What happens if a page cannot be archived?
An error message is shown and the bookmark is left unchanged. Pages behind a login or a robot protection usually cannot be archived.

Are tags shared between users?
Tags belong to their owner, who is the only one allowed to modify them. Tags of public bookmarks are shown to everyone.
